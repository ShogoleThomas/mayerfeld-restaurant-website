# Mayerfeld Restaurant Website

A modern, responsive restaurant website designed to showcase Verde Italian Kitchen, offering visitors an elegant and user-friendly way to explore the restaurant online.

## About the Project

The Mayerfeld Restaurant Website is a frontend web development project focused on creating an attractive, accessible, and responsive digital experience for a restaurant.

The website aims to combine clean design, intuitive navigation, and a welcoming visual identity that reflects the atmosphere of an Italian dining experience.

## Features

- **Responsive Design** — Layouts designed to adapt to desktop, tablet, and mobile screens.
- **Modern User Interface** — Clean typography, balanced spacing, and visually appealing styling.
- **Restaurant Branding** — A design inspired by the atmosphere and identity of Verde Italian Kitchen.
- **Simple Navigation** — An intuitive browsing experience for website visitors.
- **Lightweight Frontend** — Built using standard web technologies without requiring a complex framework.

## Getting Started

To run the website locally:

1. Clone the repository

```bash
git clone https://github.com/ShogoleThomas/mayerfeld-restaurant-website.git
```

2. Navigate to the project directory

```bash
cd mayerfeld-restaurant-website
```

**3. Open the website**

Open `index.html` in your preferred web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
